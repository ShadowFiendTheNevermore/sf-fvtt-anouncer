**ru**: 
С этим модулем вы можете создавать анонсы для своих игроков, которые будут видны только вам и им, вот несколько ключевых особенностей модуля:

* Управление по переключателям, какие игроки получат уведомления
* Можно задавать любой шаблон для сообщения (общий для всех, будет ли в разработке отдельно не знаю)
* Общая настройка для включить \ выключить отправление сообщений игрокам, пока модуль находится в активном состоянии

**en**: 
With this module you can create notification message for your players as whisper message, below the option list of module:

* Chose which player will receive your anounce message
* Customize your anounce message
* Switch option for enabled \ disable anouncer while module is enabled
